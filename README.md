# Perfect Playtime — вёрстка по макету

Откройте `index.html` в браузере — сборка не нужна (чистые HTML / CSS / JS).

## Структура
```
index.html        — разметка всех секций
css/style.css     — стили + адаптив (1200 / 960 / 640px)
js/main.js        — вся логика
assets/img/       — изображения
```

## Логика
- Корзина: добавление из карточек, Best Seller и быстрого просмотра, +/− количество, удаление, сумма, оформление; сохраняется в localStorage
- Hero-слайдер: стрелки, точки, автопрокрутка каждые 5 сек
- Слайдер Best Seller и карусель категорий
- Фильтр товаров New Arrivals (кнопки и клик по категории)
- Избранное (сердечко), быстрый просмотр товара
- Модалки Log In / Register / Contact Us с валидацией
- Подписка в футере с проверкой email
- Выбор города в верхней панели (запоминается)
- Статус «Открыто / Закрыто» по графику работы
- Бургер-меню, подсветка активного пункта меню при скролле, кнопка «наверх», анимации появления

## Важно про картинки
Фото в `assets/img/` вырезаны из скриншотов макета, поэтому они в низком качестве.
Экспортируйте оригиналы из Figma (Export → JPG/PNG, 2x) и замените файлы с теми же именами — вёрстка подхватит их автоматически.
`chair.png` должен быть PNG с прозрачным фоном.

Шрифты: Titan One (заголовки) и Inter (текст) подключены с Google Fonts.
